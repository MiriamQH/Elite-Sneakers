📝 Resumen del Trabajo
Este proyecto consiste en el diseño e implementación de una aplicación web dinámica dedicada a la gestión y venta de zapatillas de deporte.
La aplicación permite interactuar a dos tipos de usuarios (Administradores y Clientes), gestionando de forma eficiente la persistencia de datos y el estado de  
la aplicación mediante sesiones.


🏗️ Arquitectura de la Solución
Siguiendo los objetivos del trabajo de enfoque, la aplicación se ha desarrollado bajo una arquitectura de 3 capas:

-Capa Cliente: Interfaz de usuario construida con HTML, CSS y JavaScript. Incluye formularios de acceso y registro validados.
-Capa de Lógica de Negocio: Desarrollada en PHP, encargada de procesar las peticiones, gestionar el carrito y el control de sesiones de usuario.
-Capa de Acceso a Datos: Implementada mediante PHP y MySQL, asegurando la correcta manipulación de la base de datos de la tienda.


🚀 Funcionalidades Implementadas (Casos de Uso)
El sistema cubre los tres requisitos funcionales (RF) solicitados en el enunciado:

-RF01 (Gestión de Usuarios): Capacidad para crear, modificar o eliminar usuarios de tipo cliente y administrador.
-RF02 (Gestión de Catálogo): Panel administrativo para la creación, modificación y borrado de artículos (zapatillas).
-RF03 (Proceso de Venta): Navegación de artículos, sistema de carrito de compras y confirmación de pedidos para el usuario cliente.


🛠️ Tecnologías Utilizadas
-Lenguaje de Servidor: PHP 

-Base de Datos: MySQL 

-Frontend: HTML5, CSS3 y JavaScript 

-Control de Estado: Sesiones de PH
